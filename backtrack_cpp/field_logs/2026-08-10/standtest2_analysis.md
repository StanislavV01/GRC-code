# Стенд-тест №2 — розшифровка одометрії (2026-08-10)

**Метод:** борт на стенді (колеса від землі), оператор дав з пульта послідовність
`вперед → назад → розворот вліво → розворот вправо`, CM4 писав шину listen-only
(`can_sniff --esc-csv --cmd-csv`, DroneCAN 1 Мбіт). Сирі дані на борту:
`esc_standtest2.csv`, `cmd_standtest2.csv`, `sniff_standtest2.log`.

Перший прогін (`*_standtest.csv`) був непридатний: наївна склейка multi-frame
давала ~35% сміття. Виправлено в `apps/can_sniff.cpp` — коректна DroneCAN v0
reassembly (за `transfer_id` + toggle) і LSB-first декод (старий декод rpm/esc_index
був хибний). Після фікса сміття 0%.

## Результат (esc.Status від node 50, mean rpm по 5-с вікнах)

## Висновки (висока впевненість)

- **Джерело одометрії = DroneCAN `esc.Status` (data type 1034) від `node 50`.**
- **`esc_index 0` = ЛІВА гусениця, `esc_index 2` = ПРАВА гусениця.**
- **Знак rpm: «+» = вперед, «−» = назад** (однаково для обох гусениць).
- Обґрунтування ліве/праве: при розвороті вліво (оператор: ліва назад/права вперед)
  idx0 пішов у мінус → ліва; idx2 у плюс → права. Розворот вправо дав дзеркально —
  сходиться.
- (`esc_index 1` командувався, але в телеметрії майже не рухався — не ходова, або
  третій вихід; ігноруємо для одометрії.)

## Наслідок для коду

Поточний HAL `hal/vesc_socketcan` чекає **VESC-native кадри з node id left=1/right=2** —
це НЕ відповідає борту. Реальна одометрія — `esc.Status` (DroneCAN) від node 50,
`esc_index 0`=ліва, `2`=права. HAL треба переписати під це джерело. Це знімає
блокер-питання «звідки backtrack бере оберти коліс».

## Командний бік — НЕ розшифрований однозначно

`esc.RawCommand` від автопілота (node 10): `idx0` біполярний (±~8000, схоже на «газ»),
`idx1` завжди додатний, `idx2` крихітний. Пряме зіставлення команда→гусениця не 1:1 —
автопілот, схоже, шле газ/поворот, а диференціал роблять мікшер/ESC. Можливо, прямі
покомандні значення сидять у vendor-типах (напр. 20601 @ >1 кГц від node 50) або в
11-бітних не-DroneCAN кадрах. Для backtrack це не критично (потрібна одометрія, вона є).
